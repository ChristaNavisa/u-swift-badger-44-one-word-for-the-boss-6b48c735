## The entry

> Echo

The boss who hears your idea in the meeting, repeats it five minutes later in his own voice, and gets the credit for it. Every office has one; every colleague recognises him in a second.

## How it works

`main.ts` writes that single word to `/output/entry.txt` (4 characters, valid UTF-8, one word, no whitespace) and validates it first: 1–30 characters, exactly one word.

Run it with Node 22.18 or later:

```sh
node main.ts
```
